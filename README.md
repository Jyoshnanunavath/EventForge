# AI Event Management Platform

## Description

AI Event Management Platform is a full-stack AI-powered event management system that streamlines the complete event lifecycle—from planning and scheduling to attendee registration, security, resource management, and post-event analytics. The platform combines modern web technologies with Artificial Intelligence to automate event planning, optimize operations, and enhance the overall experience for organizers and attendees.

Built with both Software Engineering and Project Management principles, this project demonstrates real-world event execution while incorporating industry-standard project management artifacts such as Project Charter, Risk Register, Sprint Board, Gantt Chart, Stakeholder Matrix, Budget Estimation, and KPI Dashboard.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Jyoshnanunavath/EventForge.git

cd EventForge
```

### 2. Install Dependencies
**Backend**

```bash
cd server
npm install
```

**Frontend**

```bash
cd ../client
npm install
```

### 3. Configure Environment Variables
Create a `.env` file inside the **server** folder and add the following variables:

- MONGODB_URI
- JWT_SECRET
- GEMINI_API_KEY
- OPENAI_API_KEY (Optional)
- FACE_API_KEY
- EMAIL_SERVICE_KEY

### 4. Run the Application
**Start Backend**

```bash
cd server
npm run dev
```

**Start Frontend**

```bash
cd client
npm run dev
```

Frontend: **[http://localhost:5173](http://localhost:5173/)**

Backend API: **[http://localhost:5000](http://localhost:5000/)**
